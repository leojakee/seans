# Каталог TMDB для «Сеанса»

Запустите `node catalog-server/server.mjs` на сервере с Node.js 22 или новее. Задайте `TMDB_READ_TOKEN` через хранилище секретов хостинга. Сервер слушает `PORT` или 8080. Опубликуйте его за HTTPS.

Задайте публичный HTTPS-адрес сервера в переменной репозитория GitHub `SEANS_CATALOG_URL`. Для локальной сборки используйте эту же переменную окружения или параметр Gradle `-PcatalogUrl=https://example.org`. В APK записывается только адрес сервера.

`GET /v1/new` возвращает фильмы и сериалы для полки «Новое». `GET /v1/title/{movie|tv}/{id}` возвращает карточку. Без настроенного адреса приложение использует основной каталог.
