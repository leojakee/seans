Документ для ChatGPT и других ассистентов. Прочитай его целиком перед ответами по проекту. Состояние на 28.11.2026.

## Что это
«Сеанс» — Android-приложение «домашний кинотеатр» для телефона и Android TV, один APK на оба устройства. Оно собирает каталоги фильмов и сериалов с нескольких сайтов, показывает карточки и запускает видео: во встроенном плеере Media3 или в плеере сайта (WebView). Владелец проекта — timur, репозиторий публичный: https://github.com/leojakee/seans. Язык интерфейса и общения — русский.

## Архитектура
- **Нативная часть (Java)** — `app/src/main/java/app/seans/cinema/`:
  - `MainActivity` — WebView с интерфейсом и JS-мост `Cinema` (`@JavascriptInterface`): запросы к каталогам, история, настройки, обновления, голосовой поиск, профили.
  - `Catalog`, `WebCatalog`, `ExtraCatalog`, `Rukino` — разбор HTML сайтов через jsoup.
  - `PlaybackSources` — плееры Collaps/Vibix, раздачи JacRed.
  - `PlayerActivity` — Media3-плеер или плеер сайта в WebView. Кнопки «Качество», «Озвучка», «+85 с», автопереход на следующую серию.
  - `History` — история и позиции просмотра в SharedPreferences, у каждого профиля свой файл: `library` или `library-<id>`.
  - `Updater` — проверка GitHub Releases, скачивание и установка APK через FileProvider.
  - `WatchNext` — ряд «Далее» на главном экране Android TV (androidx.tvprovider).
  - `EpisodeAlerts` — WorkManager раз в 12 часов проверяет избранные сериалы и шлёт уведомление о новых сериях.
  - `VideoQuality`, `WebQuality`, `AudioMenu` — выбор качества и звуковых дорожек.
- **Интерфейс (HTML/JS/CSS)** — `app/src/main/assets/`. Файлы отдаются через `https://appassets.androidplatform.net/` по белому списку `FILES` в `MainActivity` (новый файл нужно добавить и туда, и в `index.html`).
  - `cinema.js` — навигация, главная из полок, карточка фильма, меню, профили, плитки, фокус для пульта (`moveFocus`, `reveal`, `focus`).
  - `search.js` — поиск по всем источникам, фильтры, автоподгрузка.
  - `feed.js` — разделы «Фильмы», «Сериалы», «Каталог» со всех источников, объединение дублей, бесконечная прокрутка (`autoLoad`).
  - `sources.js` — список сайтов, настройки, выбор озвучки (`otherSites`), зеркала.
  - `playback.js` — запуск серий, запоминание выбранного источника по сезону и серии.
  - `screen.css` — стили. Блоки ниже `/* ===== 1.8: media-centre layout` — актуальный дизайн; более ранние правила частично им перекрыты.
  - `material.js` — **собранный** бандл React + Material UI. Руками не править: исходник `ui/material.jsx`, сборка `cd ui && pnpm install --frozen-lockfile && pnpm run build`.
- **Режимы**: `body.tv` — телевизор (пульт, фокус, часы, боковое меню), без класса — телефон (нижняя панель, свайпы). Режим выбирается при первом запуске и в настройках.
- **Хранение на устройстве**: localStorage (избранное `favorites`, у второго и следующих профилей `favorites@<id>`, профили `profiles`/`activeProfile`, плитки `tiles`, кэш каталога `homeCache`) плюс SharedPreferences (история, настройки).

## UX (в стиле vi3000 / Lampa)
Верхняя панель: кнопка «Меню», логотип, поиск, настройки, на ТВ часы. Боковое меню: Главная, Каталог, Фильмы, Сериалы, Досмотреть, Поиск, Избранное, Настройки. Главная состоит из горизонтальных полок. На постерах метка TV и рейтинг, фокус обозначается белой рамкой. Сериалы выбираются по порядку: сезон → серия → озвучка (окно `otherSites` со всех источников). Палитра: фон `#1d1f20`, белый фокус, жёлтый акцент `#ffc93a`.

## Как работать
- Запуск на эмуляторе: `tools\preview.ps1` (телефон Android 14), `-Tv` (Android TV 14), `-NoBuild`, `-Stop`. Сборка: `.\gradlew.bat -PparallelInstall :app:assembleDebug`, пакет `app.seans.cinema.home`.
- Тесты: `node --test tests/series-source.cjs tests/web-quality.cjs`.
- Ветки: каждая задача в отдельной ветке от `main`, владелец сам мёрджит PR. На каждый PR GitHub Actions (`ci.yml`) гоняет тесты и debug-сборку.
- Выпуск: поднять `versionName`/`versionCode` в `app/build.gradle`, смёрджить, поставить тег `vX.Y` на `main`. `release.yml` соберёт подписанный APK и создаст GitHub Release. Приложение само покажет плашку «Доступна новая версия».
- Подпись: release-ключ лежит вне репозитория. Пароль в `source/keystore.properties` (в .gitignore), в CI — секреты `SEANS_KEYSTORE_BASE64` и `SEANS_KEYSTORE_PASSWORD`. Ключ и пароль не публиковать и не вставлять в чат.
- Стиль кода: компактный JS без фреймворков (кроме Material UI), комментарии на английском объясняют «зачем», интерфейс и коммиты на русском.

## Ограничения
- Каталоги не отдают список студий озвучки. Варианты в окне «Выберите озвучку» подписаны именем плеера или сайта.
- Часть сайтов отдаёт видео только внутри своего плеера (WebView). Прямой поток есть не у всех источников.
- WebView в release-сборке не отлаживается через DevTools, отладка — на debug-сборке (`tools\cdp.mjs`).
