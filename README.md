# Сеанс 1.7

Домашний кинотеатр для Android и Android TV 8.0 и новее. Установите один и тот же APK на телевизор или телефон. При первом запуске выберите режим. Сменить его можно через шестерёнку вверху экрана.

## Интерфейс версии 1.7

На телефоне и Android TV используются компоненты Material UI. На стартовом экране выберите режим. В верхней панели доступны каталог, поиск, коллекция и настройки. На телевизоре перемещайтесь стрелками и нажимайте OK. Чтобы начать ввод, нажмите OK в поле поиска. На телефоне запрос можно отправить клавишей поиска на экранной клавиатуре. Переключатель «Всегда максимальное качество» находится в настройках.

## Поиск и каталоги

Поиск опрашивает известные каталоги параллельно. Можно также вставить ссылку на фильм или сериал с Кинопоиска — приложение найдёт карточку по точному ID в каталоге Rukino, если она там есть. В фильтрах можно выбрать сайт, тип, годы выпуска, минимальный рейтинг и порядок результатов. Пустой запрос открывает подборку из каталогов. Кнопка «Показать ещё» подгружает следующие страницы с учётом выбранного типа. Совпадения с одинаковыми названием, годом и типом группируются по сайтам. В карточке можно добавить фильм в избранное, выбрать сезон и серию, начать просмотр или открыть поток в другом установленном видеоплеере. Для управления на телевизоре используются стрелки, OK и «Назад». Избранное, история просмотра и пять последних текстовых запросов хранятся на устройстве.

Встроенные каталоги — Rukino, Зона сериалов, Антенна, Kinonox, MaxFilm, LordTVSerials, Zona и четыре адреса Lordfilm (lordfilm.movie, lordfilm.legal, lordfilm.org и lordfilmlive.com). В настройках можно выбрать площадки для общего поиска. Кнопка «Источник» в карточке ищет то же название на других площадках. Приложение запоминает выбранный сайт и при переключении подбирает тот же номер сезона и серии, когда обе площадки публикуют список эпизодов. Антенна открывает собственный плеер внутри приложения. Основной каталог по умолчанию — lordfilm.movie. Если основной каталог недоступен, приложение пробует остальные известные адреса. В настройках команда «Найти рабочие зеркала» проверяет встроенные и сохранённые адреса, учитывает переадресации и проверяет опубликованные каталогом ссылки на новые зеркала. Можно также добавить свой HTTPS-адрес. Совместимость зависит от разметки каталога и видеопровайдера. При смене адреса сохранённые карточки по-прежнему ведут на зеркало, с которого их добавили.

## Воспроизведение

Кнопка «Источник» также предлагает плееры Collaps и Vibix, когда у них есть фильм или выбранная серия. Collaps проверяется по ID Кинопоиска, Vibix открывается через Kinonox. Оба воспроизводят видео внутри приложения в плеере сайта. Для поиска торрентов выберите «Источник» → «Найти раздачи в JacRed». Список учитывает название, год и выбранный сезон, объединяет одинаковые раздачи и показывает размер и число раздающих. При выборе раздачи Android открывает установленный торрент-клиент. Если клиента нет, можно скопировать magnet-ссылку. Для многосерийной раздачи эпизод выбирается в торрент-клиенте.

Каталог читает HTML без запуска скриптов сайта. Для запуска видео приложение открывает выбранный виджет в отдельном WebView без моста к библиотеке. Оно фильтрует известные рекламные запросы и открывает доступный HLS/DASH-плейлист в Media3 или передаёт его через Android ACTION_VIEW. Плееры, которые доставляют видео только внутри виджета, могут требовать выбора другого источника для внешнего просмотра. Встроенный Media3 сохраняет позицию просмотра. Возврат позиции из другого приложения зависит от его поддержки.

## Качество видео в версии 1.6

После выбора источника приложение готовит видео на паузе и показывает разрешения, доступные для этой серии. Выберите разрешение, при желании отметьте «Запомнить для этого сезона» и нажмите «Смотреть». Этот выбор действует и при следующем запуске приложения. Если в другой серии сохранённое разрешение недоступно, появится новый список. Чтобы снова выбирать перед просмотром, откройте в карточке серии «Качество» и нажмите «Снова спрашивать перед просмотром».

Пункт «Максимальное» подбирает наибольшее разрешение отдельно для каждой серии. **Настройки → Всегда максимальное качество** включает такой выбор для всех сериалов и фильмов и пропускает диалог. При выключении настройки снова действуют сохранённые предпочтения сезонов.

Выбор поддерживают встроенный Media3, Collaps и режим «VideoHub · меню озвучек» в MaxFilm и LordTVSerials. Встроенный плеер также позволяет изменить разрешение во время просмотра кнопкой «Качество». Во внешнем приложении и в остальных веб-плеерах качество меняется средствами выбранного плеера. Если WebView устройства или сайт не предоставляют управление качеством, можно открыть меню самого сайта или выбрать другой источник.

## Выбор источника и озвучки

При первом просмотре сезона выберите источник. Следующая серия откроется через тот же плеер. «Источник» позволяет изменить выбор, а для уже открытой серии приложение помнит её отдельный выбор. В новом сезоне прошлый источник появляется первым, если он доступен. Пометка «✂ Возможны сокращения» означает, что запись размещена на RUTUBE. Полнота конкретной копии неизвестна.

MaxFilm, LordTVSerials и Zona участвуют в поиске. В поле поиска также можно вставить ссылку на карточку любого из этих сайтов. Для ссылок lordfilmy-2026.com используется зеркало gg.maxfilm3.link. В MaxFilm и LordTVSerials можно выбрать «VideoHub · меню озвучек» и переключать дорожки через меню самого виджета. В Zona можно открыть страницу на сайте или проверить другие источники фильма через кнопку «Источник».

В Media3 и Collaps кнопка «Озвучка» показывает опубликованные звуковые дорожки. В других веб-плеерах выбор зависит от меню сайта. На телевизоре кнопка «Курсор» позволяет попасть в экранное меню стрелками и нажать OK. Кнопка «Назад» выключает курсор. Во внешнем видеоплеере озвучка выбирается его средствами.

Панель веб-плеера скрывается после нескольких секунд бездействия. На телефоне коснитесь видео, чтобы вернуть панель. На телевизоре нажмите стрелку вверх.

## Структура исходников

| Путь | Содержимое |
| --- | --- |
| `app/src/main/assets/` | Интерфейс телефона и телевизора, поиск, выбор источника для серии и меню озвучек |
| `app/src/main/java/app/seans/cinema/` | Android-экраны, чтение каталогов, работа с плеерами и хранение истории |
| `app/src/main/AndroidManifest.xml` и `app/src/main/res/` | Точки входа Android и Android TV, значок и баннер приложения |

| `tests/` | Тесты запоминания источника, выбора качества и обработки недоступных вариантов |

## Сборка из архива

Распакуйте архив и откройте терминал в каталоге с `gradlew`. Понадобятся JDK 17, Android SDK Platform 35 и Build Tools 35.0.0. Укажите путь к SDK в переменной `ANDROID_HOME` или откройте проект в Android Studio. При первой сборке Gradle Wrapper загрузит Gradle 8.13 и зависимости проекта.

Чтобы собрать «Сеанс Кино» 1.7 для обновления версий 1.5 и 1.6 и установки рядом с версией 1.4, выполните команду для своей системы.

```sh
./gradlew -PparallelInstall :app:assembleDebug :app:lintDebug
```

Для Windows PowerShell используйте командный файл.

```powershell
.\gradlew.bat -PparallelInstall :app:assembleDebug :app:lintDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. С параметром `-PparallelInstall` имя пакета — `app.seans.cinema.home`. У него своя коллекция. История и избранное версии 1.4 остаются в прежнем приложении. При локальной сборке Gradle подпишет APK отладочным ключом разработчика. Для установки поверх уже установленного пакета Android требует ту же подпись.

Компоненты Material UI и стили включены в APK и загружаются локально. Архив содержит готовый `material.js`. После изменения `ui/material.jsx` пересоберите его из каталога `ui` (Node.js 24 и pnpm 11), затем повторите сборку Gradle.

```sh
pnpm install --frozen-lockfile
pnpm run build
```

Для проверки выбора источника и качества запустите тесты в Node.js из того же каталога.

```sh
node --test tests/series-source.cjs tests/web-quality.cjs
```
